# Archive

The prototype's documents from before the spec-driven process was adopted.
Frozen: read them for background, never edit them, add to them, or build
against them. They describe the prototype as it stood when the process came
in, not `main` ([`docs/documentation.md`](../docs/documentation.md) "Present
tense; history lives in git").

| File | What it was |
|---|---|
| [`design-document.md`](design-document.md) | The brief for the one-shot prototype build. |
| [`DECISIONS.md`](DECISIONS.md) | The append-only log of calls made during the build (D1–D76). Cited elsewhere as `D<n>`. |
| [`HANDOFF.md`](HANDOFF.md) | What worked, what was stubbed, where the build departed from the brief, and what came next. |

What in them still holds belongs in [`SPEC.md`](../SPEC.md); what is still to
do belongs in issues.
